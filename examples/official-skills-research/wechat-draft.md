# 公众号稿示例：Skill 为什么要拆成一个目录

很多人第一次写 Skill，会把它理解成一段很长的提示词。更准确的理解是：它是一套可以被 Agent 复用的工作流。

一个合格的 Skill 至少要有 `SKILL.md`，里面写清楚什么时候触发、需要什么输入、应该怎样处理、最后交付什么结果。复杂任务再按需增加脚本、参考资料和模板。[S1]

这种结构的价值，在于把“会不会做”变成“能不能稳定复用”。Agent 先根据名称和描述判断是否匹配，真正需要时才加载完整指令，避免每次都把所有规则塞进上下文。[S1]

但目录结构本身不会自动带来高质量结果。真正决定效果的，仍然是清晰的边界、真实的测试用例，以及对失败情况的处理。

来源：[S1] https://learn.chatgpt.com/docs/build-skills
