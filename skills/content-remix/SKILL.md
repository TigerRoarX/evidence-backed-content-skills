# Content Remix / 中文内容改写

Turn one approved source pack into distinct platform drafts without losing provenance.
把一份已确认的研究包改成不同平台的稿件，同时保留来源链和不确定性。

## Inputs / 输入

Require a research pack or an explicitly approved source draft, target platform(s), audience, tone, length, and call to action.
需要研究包或明确批准的来源稿、目标平台、受众、语气、长度和行动号召。只有主题时，如果预期出现事实主张，先调用 `research-with-sources`。

## Workflow / 工作流

1. Extract the source pack's verified claims, inferences, unknowns, and source markers.
   提取研究包中的已核验事实、推断、未知项和来源标记。
2. Choose a platform shape instead of copying one long article everywhere. 不要把一篇长文原样复制到所有平台：
   - WeChat: thesis, context, evidence, implications, sources.
   - Xiaohongshu: searchable title, three-line hook, scannable cards, save/share payoff.
   - X: one claim per post, concise thread structure, source link where useful.
   - Zhihu: question framing, reasoning chain, counterarguments, references.
3. Preserve numbers, dates, qualifiers, and attribution. Any new example or analogy must be labeled as an example, not evidence.
   保留数字、日期、限定词和归属；新增例子或类比必须标为例子，不能冒充证据。
4. Keep claims tied to source markers. If a platform format cannot carry a full citation, add a compact source note and retain the full ledger in the delivery package.
   让主张始终绑定来源标记；平台放不下完整引用时，使用简短来源说明，但交付包仍保留完整台账。
5. Create a visual or screenshot brief only from the approved claims. Do not imply that generated artwork is documentary evidence.
   视觉或截图 brief 只能来自已确认主张，不要把生成图片伪装成纪实证据。
6. Return separate drafts, a change log, and a list of claims that were shortened, omitted, or need editor review.
   返回各平台独立稿件、改写记录，以及被缩短、删除或需要编辑复核的主张清单。

## Output contract / 输出约定

For each platform return. 每个平台都返回：

- platform and audience / 平台与受众
- title or opening hook
- title or opening hook / 标题或开场钩子
- draft body
- draft body / 正文
- source markers and compact references
- source markers and compact references / 来源标记与简短引用
- visual brief, if requested
- visual brief, if requested / 如有要求则提供视觉 brief
- compliance and editor-review notes
- compliance and editor-review notes / 合规与编辑复核说明

Do not post, send, or upload. Publication is a separate user-authorized action.
不要直接发布、发送或上传；发布是需要单独授权的动作。
